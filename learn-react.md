# Setting up environment

1. Install node version 16 or higher
2. Create a react app using vite by executing `npm creat vite@4.1.0

   ```
   npm create vite@4.1.0
   ```

   - It will require you to install vite by pressing `y`
   - Create a project name
   - Select a framework - Select React
   - Select variant - Selet TypeScript
   - After that you need to run the following to run the new react app

   ```
    cd `name of the project`
    npm install
    npm run dev
   ```
